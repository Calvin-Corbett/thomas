# Mobile Surface Scaffolds

This directory holds platform scaffolds used for companion/mobile parity tracking.

- `android/`: Android client scaffold
- `ios/`: iOS client scaffold
- `macos/`: macOS client scaffold
- `shared/`: shared cross-platform contracts
  - `shared/life_tracker/`: local SQLite life tracker CLI for daily check-ins/habits
- `site/`: public website for downloads, release notes, journey videos, and support
