## Completed Acceptance Criteria (Recent)

- `VO-073`: camera snapshot persistence requires storing zoom/pan/follow id in local storage and restoring on workspace init.
- `VO-157`/`VO-160`: office map must be keyboard navigable and include screen-reader labels on core controls.

- `VO-088`/`VO-091`/`VO-097`: assignment and dialogue now use persona-aware priority scheduling and context-aware banter triggers.
- `VO-100`: mention parsing now supports `status`, `break`, `resume`, `summon`, `focus`, and `task` commands in-office.

- `VO-121`/`VO-133`: office event bus schema and debug overlay are wired for live simulation visibility.
