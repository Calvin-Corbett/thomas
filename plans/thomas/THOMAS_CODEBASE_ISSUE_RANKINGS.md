## Scoring Model

Each unresolved issue is scored from 0 to 100 using these factors:

- User impact: severity and visibility of the bug for the product owner or end user.
- Strategic value: whether fixing it improves Thomas's core reliability, agent workflow, or architectural clarity.
- Confidence: strength of the evidence in the queue and how direct the reproduction path is.
- Implementation risk: lower risk raises the score when impact is comparable; high-risk fixes need more care.
- Suitability for autonomous completion: whether a scoped worker can likely fix and verify it without owner decisions.

Grades:

- `A`: 90-100
- `B`: 80-89
- `C`: 70-79
- `D`: 60-69
- `F`: 0-59
