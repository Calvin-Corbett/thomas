Why this page kept reporting a postMessage error. It used to load three scripts — unified_code_artifacts.js, unified_code_results.js and chat_message_view.js — and not one of them calls postMessage; only nine files under thomas/server/web/js do, and none of those three is among them. So the error was never coming from the code this page exercises. It came from outside: either the host page relaying into this page as a frame (the isOurFrame bug the section below now covers), or from opening this file directly, where the page's own origin is opaque, location.origin is "null", and a post to any frame it owns cannot be addressed at all.

So serve it — do not double-click it. From the repo root, run python -m http.server 8010 and open http://127.0.0.1:8010/tests/web_node/build_chat_browser_probe.html.
