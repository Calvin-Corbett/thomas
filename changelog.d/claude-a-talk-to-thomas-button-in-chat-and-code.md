### Added

- **A Talk to Thomas button now sits beside the microphone under the message box, in Chat and in Code.** You asked for "a little button in the composer" so you can "talk to Thomas". Press it, speak, and press it again: what you said goes into the message box and is sent like any message, to the smallest and fastest model you have set up (or to the model you chose when none is small), and the answer is read aloud. It speaks with Voice Studio when that program is running on this computer, and with your browser's own voice when it is not. The small arrow beside the button opens the voice choices, where you can change the voice at any time. One default voice is saved. The microphone beside it still types what you say into the message box, as before. Turn the Talk to Thomas plugin off and the button is not drawn, and the page asks for nothing more.
