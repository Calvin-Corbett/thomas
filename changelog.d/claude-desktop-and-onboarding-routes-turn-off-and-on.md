### Changed

- **The isolated desktop setup and the first-run measurements can now be turned off and on while Thomas runs, each on its own.** The six `/api/onboarding/desktop` routes moved into a plugin called Isolated desktop setup, and the other three `/api/onboarding` routes into one called First-run measurements. Both ship on, so nothing changes until you turn one off. With Isolated desktop setup off, Isolated Desktop Mode under Advanced in Settings stays on the page and does not say it is off: Save Desktop Settings shows a green Isolated desktop settings saved although nothing was saved, and Install Host Service and Open Viewer show a red failure. Mission Control and Easy Setup stop reporting the isolated desktop, and a server started with it off never loads the desktop helper's code. Turning it off stops a desktop helper this Thomas started. With First-run measurements off, Easy Setup still opens on a new install over Virtual Office, Canvas, Channels, Token Economy and Marketplace and on the older full page (Chat itself never opens it), and you can finish or skip it there as before, because your choices are saved through Settings. What stops is the note of each step, which Easy Setup sends without waiting for an answer.
