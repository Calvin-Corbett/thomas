### Changed

- **The browser tools can now be turned off and on while Thomas runs, and Thomas closes the browser it started.** The eight browser tools (open, click, type, screenshot, extract, close, console and network) moved into a plugin called Browser tools, which ships on, so nothing changes until you turn it off. Off, a chat message or Build run started afterwards has no browser tools, and a run that already holds one is refused at once with a message saying the browser is turned off, instead of waiting. Off, and when Thomas closes, the Chromium that Playwright started is closed with every page in it, which nothing did before at shutdown, and turning it on again starts with a blank browser. The browsing switch under Autonomy in Settings is still your permission and is not touched by this plugin: Thomas browses only while both are on.
