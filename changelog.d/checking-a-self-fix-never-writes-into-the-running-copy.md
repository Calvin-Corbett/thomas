### Security

- Checking a self-fix no longer writes anything into the running Thomas. For a file a change adds that the tree it is checked against already has, git's three-way apply checked that tree's version out into the running copy wherever the file was missing: it could put back a file you had deleted there, and, checking one change on top of another for a shared card, it wrote the first change's file before you had approved it. Every check now applies a change in an empty folder of its own.
