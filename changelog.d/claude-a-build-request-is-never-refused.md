### Fixed

- **An ordinary build request is no longer refused outright.** "Build dice.html… then open it and confirm the button works" came back `Task hand-off failed: Build task needs correction: uncited_acceptance`. Intake called the dispatch validator without `repair_attempts`, so it defaulted to 0; with a repair budget of 2, `dispatch_anyway` could never become True and the escape hatch was unreachable code — the validator could refuse forever, which is the one thing its own docstring says it must never do. There is no repair loop at that call site, so the budget is not untouched but already spent; saying so makes the designed behaviour reachable. The task now goes out with the uncited acceptance items dropped and its end state degraded to `completed_unverified`, instead of the work never starting.
