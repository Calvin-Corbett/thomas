### Changed

- **The run history routes can now be turned off and on while Thomas runs.** The ten `/api/runs` routes moved out of the server's fixed list into a row called Run history for other programs, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404 and a program part way through reading a run is cut off, and nothing you normally use changes, because no page in the sidebar or Settings reads them. Thomas goes on recording replies in Chat and jobs in Build, and Mission Control goes on listing the recent ones, because the run store stays with the server. If you still have the older full page open, the Runs tab of its Tools Console reads 0 at its next refresh and says the endpoint is not available. If the run store does not open when Thomas starts, this row now reads Didn't start on the Plugins page with the reason, where before the only sign was a line in the log.
