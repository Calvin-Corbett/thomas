### Fixed

- **The Agent picker's "Default" names the agent Build will actually run in the conversation you have open.** With an Anthropic key saved, an unpicked turn of a Build conversation that ran on Claude Code stays on Claude Code, but the picker asked only with the chip's model and so said "Default (Thomas)"; only the run report said otherwise, after you sent. `GET /api/evolve/agent/agents` now takes an optional `conversation_id` and answers with the same rule Build uses (one shared function, `kept_agent` in `agent_continuity.py`), so the option reads "Default (Claude Code)" and its tooltip gives the report's own sentence ("No agent was picked, so this conversation stayed on Claude Code, which ran its earlier turns. Pick an agent to change it."). The picker sends the conversation open in the active tab's Build view, and asks again when you switch tabs, when a tab moves between Chat and Build, when Build opens or starts a conversation, and when the open conversation gains a turn. With no Build conversation open, or an id that names no conversation, the answer is the one a new conversation gets, as before. The route looks up only ids made of letters, digits, `_` and `-`, since the conversation store turns the id into a file name.
