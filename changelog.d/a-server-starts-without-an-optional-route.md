### Fixed

- **A server no longer refuses to start over one optional route.** The named calls landed in `cd801cda` made the server stop if a provider was missing, and one provider, the self-project queue tick, loaded only through a route family that is allowed to fail with a warning. If that family could not load, a warning became a server that would not start. The server now loads that provider itself. A new test removes every optional route family in a fresh process and starts the server, because in a shared test process any earlier test's import hides this.
- **A test can no longer start the real server by accident.** One test re-imported the CLI and put back only half of what that moved. A later test's stub then landed on a copy nobody calls, and the real `thomas serve` ran inside the test for 15 minutes until its worker was killed. Both halves are fixed, and if a stub misses again the test fails at once.
- **A test run no longer opens your real secrets file or `~/.thomas`.** The test run's own tripwire had been saying so in every full run. A helper that was meant to isolate a test deleted the setting that keeps tests out of your secret store, and the tray tests found your home folder when they were imported. Your `secrets.json` was opened, and your `tray_state.json` was read and not changed.
- **Every test starts with an empty task ledger and no Build projects.** Both were shared by every test on a worker, so a test could pass or fail by what ran before it. Three tests did, including one that replaced this with a stub of its own in the last change.
