### Fixed

- **A Thomas project's copy can take dev in, and then hands in only its own change.** The ChatGPT sign-in project ran out of repair rounds without its change ever reaching your card. Thomas's merge of dev into its copy failed on Thomas's own board file ("Entry 'plans/thomas/WORKBOARD.md' not uptodate"): a hand-in keeps the board out of the change in git's index only, so the copy's board on disk no longer matched, and git will not move a file like that. The copy's board and problem logs on disk are now put back before the merge; they are never handed in. The round then told the team to merge dev itself, which moved the copy onto dev but not the point its hand-in is measured from, so every hand-in after that carried all of dev's own commits (93 files) and could never apply. A copy whose history already holds a newer dev commit now measures its hand-in from that commit.
