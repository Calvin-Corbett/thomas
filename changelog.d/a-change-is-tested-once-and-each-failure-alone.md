### Changed

- **The check before your card runs the tests that cover a change once, with the change, instead of a second time on dev as well.** Each failure is then re-run on its own, with the change and then on an unpatched copy of dev; each re-run has its own report and its own data folder, so the re-runs go side by side. A failure is set aside only when it passes on its own with the change or fails on its own on dev, and one that dev failed beside other re-runs is re-run on dev once more, one at a time, before it is set aside. A failure that dev's own full run also had is no longer excused for that alone. Dev runs in full only when the change's run stopped before the end, more than 40 tests failed, or all that is left is failures no re-run on its own could settle. If dev itself is the problem there (its own run does not reach the end either, or it fails every failure left unsettled), the change is held for another try with no strike against it, instead of going back to its team. A change whose own run broke while dev's ran to the end still goes back. A change whose own test process would not start is the check's own trouble: it is held with a strike against it, whatever dev does, and dev is not run. While its tests are held for dev, a ruff finding or a size problem still sends the change back. A test process or a re-run that the pool of test processes could not give a place holds the check for another try, never counting as a failure, unless something proven on its own sends the change back; when the change's own run is the one given no place, dev is not run in full. Which tests dev is known to fail is kept by dev tree, interpreter and environment, and only decides which failures are re-run last; it never excuses one. With `THOMAS_PRECARD_PARALLEL=off`, the one run gets the whole allowance, with the memory reserve counted once. The card now says the tests ran with the change and how many failures were re-run on their own, and the findings say how many failures were re-run on their own and why any others were not (past the first 40, or given no place). A check kept from before this change is run again, never reused.
