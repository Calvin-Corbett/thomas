### Added

- Build teams can select exact connected model profiles per file, including guarded Claude CLI writers, while the saved Luna profile remains the default.
- Praxis journals Build-owned writers and resumes server-owned read agents after a server restart. The Code card shows recovered child status and a disconnected Build lead.
- Build team size is unbounded; concurrent waves use current CPU and available memory. Durable receipts remain available when a pass stops.

### Fixed

- Missing independent Build verification stops with incomplete evidence instead of charging a builder for an unsupported repair.
- Rejected Praxis plans now tell the Build lead the server's bounded refusal reason so it can revise the plan.
