### Changed

- **The Canvas layout routes can now be turned off and on while Thomas runs.** The five `/api/canvas` routes, which save a layout, load it, turn it into code and ask a model for a layout, moved out of the server's fixed list into a row called Canvas layout saving and AI, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404. Canvas still opens and still shows the code you generate, but Save shows Save failed. and the AI Template and Import Sketch buttons say no layout came back. Nothing in Canvas asks again on its own. Layouts already saved stay where they are, and the helpers that save or read a layout for an assistant now share one small file with the routes instead of importing the routes, so they keep working while the routes are off. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart.
