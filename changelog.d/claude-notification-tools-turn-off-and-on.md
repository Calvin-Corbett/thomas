### Changed

- **The notification tools can now be turned off and on while Thomas runs, and a tool can no longer reach a database outside its own folder.** The six `notifications_*` tools and the notice a delegated task sends moved into a plugin called Notification tools, which ships on. While it is off Chat and the workers Thomas starts are not given the tools, a worker that already has them is told notifications are turned off, and no record of a task's ending is saved; the ending still reaches Chat. The tools used to open whatever database path a model sent them, and now keep every store inside a `notifications` folder under Thomas's memory folder, refusing another drive or a network name from the text before the disk is touched. Only opening a store, counting the unread ones and marking one read by its id work today: create, list, clear and mark all read call store methods that do not exist, and the plugin's words say so. The command line version no longer has the six tools, because it does not load plugins.
