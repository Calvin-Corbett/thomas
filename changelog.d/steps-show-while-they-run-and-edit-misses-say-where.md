The live record of a run held only finished steps, so a ten-minute test run was silence until it ended. When the model finishes asking for a tool, the record now says which tool is starting and with what. The Code page leaves these lines out, because the step's result is its row.

On 2026-10-26 three teams each missed the same edit three times or more in an hour, editing from a reading of the file that their own earlier edits had changed, and "not found" told them nothing about what was there instead.
