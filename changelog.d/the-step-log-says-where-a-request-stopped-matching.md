### Added

- **The step log now says, for every request Thomas sends to a ChatGPT model, which part first differs from the request before it.** After each run got its own prompt-cache key, the share of prompt tokens served from the provider's cache was 25.0%, not higher (29.4% before): each call resent about 90% of the call before it, yet the cached count sat at one number for a whole run, so something near the start of the request changed on every call. Driven offline, Thomas's own requests only ever grew at the end, and Build runs keep no copy of what they send. So each request now writes a `request` row naming the first changed part (the tools, the instructions, or which input item, and what kind of item it was and became). Only that verdict is written, never any prompt text. An hour of real runs will show where the cache is lost, before anything else is changed for it.
