### Changed

- **The nine routes that let other programs see what Thomas has pinned and how much it holds, pin a fact or forget a pinned one, and settle memory changes waiting for a decision can now be turned off and on while Thomas runs.** They moved out of the server's fixed list into a row called Memory controls for other programs, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404, and nothing you normally use changes, because no page in the sidebar or Settings reads them. Other programs lose these controls. They can still chat with Thomas, which uses what it remembers, and deleting a chat still forgets what came from it, apart from any fact Thomas saved to keep. Thomas goes on remembering and goes on using what it remembers in chat. For a chat a program names, these routes also show what Thomas searched its memory for, which can be your own words from that chat. If you still have the older full page open, the Memory tab of its Tools Console will say memory is disabled once it next refreshes, which is not true of Thomas, and the Plugins page tells you so. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart.
