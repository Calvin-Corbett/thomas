### Added

- **The installer adds Stop Thomas and Restart Thomas to the Start Menu, and uninstalling stops a Thomas that is running.** The Thomas shortcut starts the server without a window, so closing the browser leaves it running and there was no window to close. **Stop Thomas** runs `launch-thomas.vbs /stop` and **Restart Thomas** runs `launch-thomas.vbs /restart`; each shows what happened. The uninstaller now runs `run-ui.ps1 -Stop` hidden before it removes the files, so a Thomas with no window is not left running from a deleted folder; when a Build run is active `-Stop` leaves that Thomas running (exit 3) and the uninstall carries on. `README.md`, `ONBOARDING.md` and the Windows installer guide now say that the server runs without a window and how to stop it, with the `-Stop` exit codes (0, 3, 5 and 6), the message shown once, the launch logs in `runtime\logs` and the `-Restart` switch.
