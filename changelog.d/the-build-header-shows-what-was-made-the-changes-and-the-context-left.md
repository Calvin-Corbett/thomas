More than five shows a "+N" that opens the Activity drawer. **The running changes:** "+28 −4", green and red, the lines added and removed across the files this task changed. It is a total you read, not a button. **The context meter:** a thin bar and "65% left" for how much of the model's context window the lead has used, taken from the lead's own token count at each model call (amber past 75% used, red past 90%). Hover it to see the token numbers. The meter shows once a run has made its first model call, so it needs a Thomas restart to start reporting.
