### Changed

- **The setup routes can now be turned off and on while Thomas runs.** The eight routes behind Easy Setup moved out of the server's fixed list into a row called Easy Setup checks and repair, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404. A Thomas that has finished or skipped Easy Setup carries on as before. On a new install Easy Setup still opens, says its check failed and recommends nothing, and while ChatGPT and Manual API Key can still be finished, Local Ollama cannot. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart. A repair or a model download Easy Setup started that is already running holds the switch until it ends, unless you press Stop now, which drops the download and leaves the repair running to its end. A model download another program started stops at once.
