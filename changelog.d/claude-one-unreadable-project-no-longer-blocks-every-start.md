### Fixed
- One Thomas project file that cannot be read no longer stops every project from starting. Before, the Improve Thomas panel said "More cannot start: Thomas projects could not all be read" for as long as any one conversation file stayed unreadable, so neither the automatic loop nor your Start button could start anything. A file that fails to read is still retried, and the list waits for it, as before; once it has failed three scans in a row it is skipped and named on the panel with its id and why. A skipped copy in a project folder still holds one project slot, so skipping never makes room that might not be there.
