### Fixed

- **Thomas closes in seconds, not minutes, when a restart has been decided.** On 2026-11-09 the server behind your desktop app wrote its exit record and was still alive 261 seconds later; until it left, the next server could not start and the app was unreachable. Its own stack snapshots showed what was still running: the survey that reads every self-fix copy with git, eight reads at a time, and the survey that asks git about each of about 150 old branches. Both only read, and neither looked at whether the server was closing. Now any background thread can ask whether Thomas is closing, and both surveys ask between steps and stop. Nothing a closing server was writing is cut short: only these two reads end early, and a copy whose read was cut short is read again next time.
