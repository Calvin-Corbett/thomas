### Fixed

- **A finished change no longer stops before your card because the check tripped on its own copy.** The check runs a change's tests in a copy of Thomas kept inside his data folder, with the copy's git folder beside it. Since 2026-11-06 Thomas reads the commit he runs from git's own files, so a test that starts a server opened that git folder, and the rule that no test may touch your real data counted it. Both sides of the check failed the same way, the check blamed dev, and the change was tried again: on 2026-11-10 one change was checked three times, 72, 29 and 23 minutes, and never reached you. The copy's own git folder now counts as part of the copy. Every other file in your data folder still fails the run, another copy's git folder included.
- **Half a check copy left by an earlier try no longer stops the next one.** A try that died could leave only the copy's files or only its git folder. Nothing removed such a half, and the next try refused to make a copy under the same name: one change was stopped three times in under a minute each on a half almost four days old. The next try now removes the half first, and checks in a fresh copy beside it when Windows still holds it open.
