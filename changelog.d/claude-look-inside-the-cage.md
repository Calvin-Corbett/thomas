### Added

- **You can see what the caged Thomas is running.** You asked, more than once, why Thomas could not be seen: on 2026-11-09 there were 95 Python processes on your PC and nothing could say what they were, because Windows hides the command lines of the cage account from yours. The cage's own server now answers, read only and only from this computer: every process it runs, what each one is (the server, a Build agent, a test run, a browser a test opened, git, a console host), the share of the whole PC's processor each used over one second, and a count and total for each kind. A program started from the project environment shows as two processes, and the half that only starts the other is named as that, so twelve Build agents read as twelve. It also answers what each Build run did last, how long ago, and whether it looks stuck: the same call four times, the same error three times, or sixty tool calls with nothing written. Anything that looks like a password or key is hidden. This is the plugin "Look inside the cage"; no page shows it yet.
