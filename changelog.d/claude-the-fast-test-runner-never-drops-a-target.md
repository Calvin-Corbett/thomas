### Fixed

- **`scripts/fast_tests.py` can no longer report a pass for tests it never ran.** With more than five targets it used a directory run plus an ignore hook, which silently dropped any `file::nodeid` target and any named file that is not called `test_*.py`: six passing files plus one failing node id and one failing named file reported "6 passed" and exited 0 where plain pytest fails. Every target is now passed through (anchored to your folder, node ids untouched), the directory form is used only when every target is a plain `test_*.py` file or a folder, a named file that produces no outcome fails the run, and `--parity` fails when the two runs executed different test ids.
- **The runner no longer shares one bytecode folder between different trees when git fails.** `tree_key` returned the hash of the empty string for every tree it could not name (not a repository, dubious ownership); it now returns nothing, the run caches no bytecode and says so. The default cache folder is also per user.
- **Workers no longer inherit `THOMAS_*` variables.** All of them are removed from the workers' environment and their data, runtime, memory-root and home folders point at a scratch folder, as the audit's scratch helper does, so several xdist workers can no longer write the real runtime. It is an opt-in tool nobody calls yet: the person running a hand-picked selection is the expected caller.
