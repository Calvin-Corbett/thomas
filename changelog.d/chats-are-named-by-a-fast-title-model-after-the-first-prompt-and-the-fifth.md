### Added

- **Chats are named by a fast title model: from the exact first prompt, then again from the whole chat after the fifth.** You asked for the auto-naming to be its own request, sent to a fast model, firing after the fifth prompt with the full context. After each saved reply the page asks the server whether it is time. The first time, the exact first prompt is sent to the title model and the answer becomes the chat's name in Recent. After your fifth prompt the whole chat goes to it and the chat is renamed to fit where it ended up. Names are kept on the server beside the chats, so every window shows them; a name you typed yourself still wins. The title model is the "title" role in the advanced model settings, so you can change it; until you do it is `gpt-6-luna` at low reasoning effort. The older batch naming of long titles now uses it too, instead of the main model at its highest effort.
