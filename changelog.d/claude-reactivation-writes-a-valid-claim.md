### Fixed

- **One task reactivation could stop every agent in the repository from committing.** `reactivate.py` wrote its claim row with `agent`, `scope` and `task` only — the three names in `REQUIRED_CLAIM_FIELDS`, which was the whole contract when that line was written. `name`, `role` and `parent` became required later in `REQUIRED_CLAIM_FIELDS_WITH_IDENTITY` and this caller was never brought along, so the row it produced failed validation. A malformed claim row does not fail only for the agent being reactivated: `commit.py` reports `could not resolve active claim` and refuses, so the whole board goes unusable. Observed the moment a long-blocked P0 finally reactivated. Reactivation now emits the identity fields, and `tests/test_a_reactivated_claim_is_well_formed.py` checks the row against the gate's own parser rather than against a hand-written expectation, field by field, so a tenth required field fails there instead of at the next reactivation.
- **Reactivation no longer demotes a worker to a solo agent.** Carrying the previous row's identity forward has to read that row with the claims gate's parser; `workboard_issue`'s returns only `{agent, scope, task}`, so preserving from it reports every identity field as absent and silently rewrites `role=worker; parent=<coordinator>` to `role=solo; parent=none` on every reactivation — while looking like it worked. The first version of this fix did exactly that and the gate's own validator caught it.

### Changed

- **One rule, one registry.** `workboard_claims.py` and `claim_ownership.py` each declared their own copy of `SHARED_INFRASTRUCTURE`, equal only by coincidence. The gate refuses a claim; the other module answers which agents hold a path. A path added to one and not the other deadlocks through whichever half was missed, and nothing reports it — the same one-rule-two-registrations shape that let the workboard inbox gate run advisory in `.pre-commit-config.yaml` while `commit.py` invoked it blocking. `claim_ownership` now re-exports the gate's set instead of restating it.
