### Changed

- **The Pull request review section can now be turned off and on while Thomas runs.** The eight `/api/pr-review` routes moved out of the server's fixed list into a row called Pull request review, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404, the rest of the Agent Ops page goes on working, and the section still says LIVE and does not tell you it is off: a press that needs Thomas shows only a small red HTTP 404, which is out of sight if you have scrolled down to a lower change. Thomas keeps your reviews while it is off, and a page you left open carries on where it was when it is back on. A restart still loses them, as it always did. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart.
