### Added

- **The first time you turn live talk on, a window in the middle of the screen says you don't have voice set up and offers Set up later or Set up now. Set up now does the whole job: it installs Thomas's speech engine when it is missing, downloads the listening model once from its makers (NVIDIA Parakeet TDT 0.6B v3, about 670 MB, CC BY 4.0), checks every file against its published SHA-256, shows how far it has got, and then live talk listens with it.** You asked how other people would get this: "this is a product. That other users need to use. So how are they going to use it? When they download Thomas." Until now the model only worked on the computer it had been copied to by hand. None of the model's files are in the repository, so the only licence in it stays MIT. The models Thomas can set up are a list in `thomas/server/voice_ears_models.py`, each pinned to one published revision with its size and checksum, and one is the default, so another can be added as one entry. Set up later, or hiding the window while it downloads, keeps live talk working with Voice Studio or the browser's own hearing, and live talk switches to Thomas's own hearing the moment the download is done.
