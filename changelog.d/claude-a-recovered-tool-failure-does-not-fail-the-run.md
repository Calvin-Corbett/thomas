### Fixed

- **A Build run that moved past a failed tool call is no longer filed as crashed.** A run that changes no files counts as failed when a tool call in it reported failure, because that is the sign of an edit that did not happen. It was read as any failure anywhere in the run. So a run confirming finished work that met a search with no match, a probe that exited 1, or a refused option before every later check passed was filed as crashed. Four finished Thomas projects never handed in, including the one fixing this. Now a failed look never counts. A failed file edit, or an unnamed call, stands until a later file edit succeeds. Any other failed call stands until a later call that can write succeeds. The in-process dispatcher, the Claude dispatcher and the server's transcript check apply the same rule.
