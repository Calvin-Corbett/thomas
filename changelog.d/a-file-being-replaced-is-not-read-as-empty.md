### Fixed

- **A repair round is no longer lost to a read at the wrong moment.** Sending a change back to its team removes the copy made when it was handed in. On Windows a reader holding that file open refuses the delete, and the failure was silent, so the copy stayed, Build refused the repair round as already settled, and refused every retry after it. The delete now waits out the reader, and one that still fails is logged. In 240 runs of the refusal test under load, 17 failed before this and none after.
- **A file being replaced is no longer read as empty.** Windows refuses a read during a replace: 8% of plain reads under contention on your machine. The conversation registry read as empty, so the next bind could write back one row and lose every other conversation's project. A hand-off record read as empty, so the next hand-in reused an id and was refused with "submission already exists". All three readers now wait out the writer, and a read that stays refused still fails as it did.
- **Two writers no longer share one temporary file.** The registry used one fixed name and a hand-off record one name per process, while two threads read each verdict. One's rename took the file from under the other's, or Windows refused it, and a successor project could fail to start.
- **A test no longer leaves a model choice behind for the next one.** `/model` saves your choice for real, and two tests saved `Local` into the file the process shares, so nine later tests in that process hit "Build cannot run 'qwen2.5-coder:7b'". They now save into their own file.
- **A test no longer takes the sleep out of every thread.** `module.time` is the one global `time` module, so a test skipping its own waits also stopped the waits in background loops left running by earlier tests. They ran flat out and starved it: a test that takes 12 s had not finished after 900, and the timeout killed its worker. `tests.sleep_support.skip_sleeps` skips them on the test's own thread only, and a guard keeps the old patch out.
