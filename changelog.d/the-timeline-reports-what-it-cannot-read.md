### Fixed

- **`scripts/praxis_timeline.py` says so when it cannot read a project.** A project whose only conversation copy sat in the caged account's green was skipped without a word. It is now also found through the catalog's project registry, and a copy this account cannot open is listed in `meta.unreadable`, counted in `aggregate.projects_unreadable` and named in the summary line. `--baseline-out` writes nothing and exits 3 while any project is unreadable, unless you give a second `--green-root` (a folder of exported copies) that holds it, or pass `--allow-unreadable`.
- **A stopped project no longer counts as open.** A project with no landing, retirement or final verdict was followed to the time you run the tool, so the Part 3 building share read 0.835 where it is 0.318. It now ends at its last event once its conversation has been quiet for an hour with nothing waiting (no hand-in without a verdict, no run going, no usage-limit pause), the same hour the server uses.
