### Changed

- **The API key routes can now be turned off and on while Thomas runs.** The four `/api/secrets` routes moved out of the server's fixed list into a row called Saving API keys, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404. Your saved keys stay saved and whatever uses them goes on as before, because the key store stays loaded. The Chat model menu looks the same, but pressing Save under a provider with no key shows 404: Not Found and the key is not kept. On a new install, Easy Setup says it could not save the key and tells you to check the key's format, though nothing is wrong with the key. Neither place says the row is off. The key boxes in Settings, signing in with ChatGPT and the key boxes for creating images, music and video do not use these routes. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart. A remote caller with no token is now held by a test to be refused on all four routes.
