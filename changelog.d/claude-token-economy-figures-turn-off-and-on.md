### Changed

- **The Token Economy figures can now be turned off and on while Thomas runs.** The nine routes behind the Token Economy page and the prices on the cost line in Chat moved out of the server's fixed list into a row called Token Economy figures, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404. The cost line in Chat still counts tokens. A Chat page already open keeps showing dollars, and one you reload loses them until the row is back on and you reload it again. A Token Economy page already open keeps its counts until you change its Window. That empties Token history, which then reads awaiting first API call as if nothing had been counted, and takes the bar under today's count and the percent under the average with it, and they stay gone until the row is back on and you press Refresh. The page's open event stream ends as soon as you press off, so it cannot hold the switch. Reloaded, that page reads no calls and no history and still says Live, and does not say why. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart. Thomas goes on adding to its record, and the spending limit on its upgrade runs still applies.
