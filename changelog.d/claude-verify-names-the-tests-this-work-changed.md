### Fixed

- **A Build team's `VERIFY:` line is now asked for the tests its work changed, not the whole suite.** On 2026-10-07 six Thomas Build teams at once ended their replies with `VERIFY: python -m pytest`, the whole ~13k-test suite (about 53 minutes). The finish check runs that command with a ten-minute clock, so each one ran for the full ten minutes and then failed. The instruction every team gets asked for "one shell command that exits 0 only if the task is complete", which in a big project reads as "run everything". It now asks for a command that checks this work: name the tests that cover what the work changed (for example `python -m pytest tests/test_<name>.py`), or, for work no test covers, a script or a check of the file it made. It also says the command runs with a limit of a few minutes, so it must not run the whole test suite. The `EVIDENCE:` line and the rule that a reply without a passing `VERIFY:` is not finished are unchanged. (`thomas/core/acceptance_contract.py`, `tests/test_acceptance_contract.py`)
