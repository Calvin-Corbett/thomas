### Changed

- **The engines list, the tools list and the landing heartbeat can now be turned off and on while Thomas runs.** `GET /api/engines`, `GET /api/tools` and `GET /api/landing-health` moved out of the server's fixed list into a row called Server status lists, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404 and Thomas keeps its engines and its tools. The Tools panel on the older full page then shows Total 0 and No tools in registry, and, once you press Refresh, Engines 0 and No engine rows returned. It asks once per tab you open and never on its own. The command line's check of a running Thomas shows its engines as not ok and still calls Thomas healthy. The Idle awareness words now say its engine listing is visible while this one is on.
