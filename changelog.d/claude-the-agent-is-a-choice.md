### Added

- Build now has an Agent choice next to the model choice, in Build and in Chat's delegation to Build. Before this, the model's family decided the agent: a Claude model ran on Claude Code and a GPT model ran on Thomas's own loop. The picker offers Thomas and Claude Code. "Default" leaves the choice to Build, which picks Thomas wherever it can run the model. An agent that cannot run the chosen model is shown with the reason instead of being hidden. A pick is followed exactly, or refused with a sentence naming the agent and the model; it is never swapped for another agent.
- Each coding agent is a spec in one registry (`thomas/core/coding_agents`). It declares whether it is installed and signed in, which model families it runs, how its launch is planned, and which pass function runs it. The picker and the runner's list of agents read that registry, so neither changes for a new agent; the launch journal records the chosen agent as plain text. Build's settings still decide some things by checking for Thomas or Claude Code: what is pinned for the run, how its model is recorded, and which credential it is handed. So a new agent such as Codex CLI needs those taught as well as its spec and pass function. An agent for another family, such as Gemini CLI on Gemini models, also needs Build taught that family, because Build refuses any model that is neither GPT nor Claude.
- Thomas's own loop can now run Claude models through an Anthropic API key (`ANTHROPIC_API_KEY`), so the default agent does not depend on driving Claude Code with a personal subscription. With no key, an unpicked Claude run stays on Claude Code as before. If you pick Thomas for a Claude model without a key, it is refused with a message naming both fixes: add the key, or pick Claude Code.
- Every Build turn records which agent ran it, next to the model (`agent` on the turn, `effective.agent` and `support.agent` in the capability report, and `agent` in the Praxis launch journal). Shell access and the record of what ran are still decided by Thomas, not by the agent. A bound self-edit's permission to build in a copy without git history is passed through to Claude Code too, though Build's send route still starts a self-edit (Edit Thomas) run only on GPT. Both agents' passes accept a protected-file fence, but Build's runner does not fill one, so neither agent gets a fence from it yet.
