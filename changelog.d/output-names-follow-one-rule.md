### Fixed

- Read folder paths such as `config/application.properties`, `models/x.safetensors`, `site/site.webmanifest`, `app/Info.entitlements`, `app/Main.storyboard`, and `ios/App.xcodeproj` whole, dropping trailing `:42` line numbers instead of truncating long extensions. Apple `.xcodeproj`, `.xcworkspace`, and `.xcassets` bundle folders are read whole but are no longer required output files.
- Backticked long-extension file names `application.properties`, `x.safetensors`, `site.webmanifest`, `App.entitlements`, and `Main.storyboard` now become required outputs when missing. Backticked code members such as `document.querySelector` stay non-outputs; short names such as `console.log` and `json.dumps` stay outputs as on dev. The 41-name `_JS_LIBRARY_FILES` set prevents missing bare JavaScript library names, including `three.js`, `node.js`, `Next.js`, `Vue.js`, and `socket.io`, from becoming required outputs. Existing library files remain recognized as file references rather than missing outputs, and qualified paths such as `vendor/three.js` remain required outputs when missing.
