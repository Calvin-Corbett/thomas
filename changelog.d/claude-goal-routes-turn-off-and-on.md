### Changed

- **The goal routes can now be turned off and on while Thomas runs.** The six `/api/goals` routes moved out of the server's fixed list into a row called Upgrade goal counts, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404, and nothing you normally use changes, because no page in the sidebar reads them. If you still have an older page open that counts these goals, it keeps its old number until you reload it, then leaves them out and does not say so. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart. Thomas keeps the list and goes on updating it. The goals you set in chat are a separate list, one for each project, and are not affected.
