### Changed

- **The rate limit line in Chat and the Export Logs button can now be turned off and on while Thomas runs.** Their three routes moved out of the server's fixed list into a row called Rate limit line and log export, which ships on, so nothing changes until you turn it off. While it is off the line in Chat can no longer say which plan has reached its usage limit or when it resets, and says nothing about a limit already running when you open Chat. If a message runs into a resting model the line still counts down, but that countdown can end long before a usage limit does. A reply that fails because of a usage limit still tells you so, with the reset time when the provider gave one. After you reload Settings, Export Logs is grey. If Settings is already open it still looks ready, and pressing it says the export failed. Thomas goes on resting models and writing its logs. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart.
