### Fixed

- **A Build's test run keeps its place in the line when the Build's pass ends, and waiting is not shown as a failed check.** Each pass of a Build ran its tests on the pass's own loop, so a run still waiting gave its place back when the pass ended (10, 30 or 60 minutes) and joined again at the back. Test runs now wait and run on one loop for the whole Build, so the next pass finds the same run. The Build screen showed "Check verdict unavailable" with a cross, and counted a failure, every time tests were still waiting; it now shows them as waiting. A verdict nobody was waiting for is no longer handed to a later call when an edit cannot be seen (no git) or a fresh run was asked for. A run whose own files (bytecode) changed the project's fingerprint was ended and started again; bytecode no longer counts as an edit, and a run is restarted at most twice in a row.
