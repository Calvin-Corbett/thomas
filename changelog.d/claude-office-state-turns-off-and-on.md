### Changed

- **Which agent the Virtual Office follows can now be turned off and on while Thomas runs.** The two `/api/office/state` routes moved out of the server's fixed list into a row called Who the Virtual Office follows, which ships on, so nothing changes until you turn it off. While it is off those routes answer 404, and the Office still opens with its agents moving and no message to say this is off. The next time it opens it goes straight to its newer floor plan instead of starting on the older tile map, and the button on the small map reads Hide instead of Follow. No agent is followed there, because following moves only the tile map. If you use the Classic layout, the Chat button at the top right of the Office opens a chat that can follow an agent. While this is off, that chat saves the agent and may tell you it worked, but the Office on your screen does not change. An Office already open goes on following until you reload it. A different agent you pick there is not saved while this is off, but your browser remembers it. A server started with the row off never loads the routes' code. Turned off on a running server, the routes go at once and their code stays loaded until the next restart. Thomas keeps the saved agent while this is off. When you turn this back on, the agent your browser remembers can replace the saved agent the next time the Office opens, or it may not, so you cannot count on which one the Office follows.
