### Changed

- **The model routes can now be turned off and on while Thomas runs.** The seven routes that list your models and test a connection moved out of the server's fixed list into a plugin called Model list and connection tests, which ships on, so nothing changes until you turn it off. While it is off the model button in the top bar of Chat, Build and Work reads Loading with no models in its menu, and a message you send from Chat or Build is not sent: the page says the selected model is not ready, and your text stays in the box. Easy Setup's Connect and Test ends in a failure, and a page you already had open before turning it off keeps its models until you reload it. None of these pages asks again and again. The version route, which the start-up checks and the debug dock ask, stays with the server and keeps answering. The daily refresh of the model list stops with the plugin, and starts again when you turn it on.
