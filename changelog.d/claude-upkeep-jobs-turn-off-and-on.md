### Changed

- **The route that starts Thomas's upkeep jobs can now be turned off and on while Thomas runs.** `POST /api/engine-actions` moved out of the server's fixed list into a row called Upkeep jobs on request, which ships on, so nothing changes until you turn it off. While it is off that route answers 404, other programs can no longer start the jobs, and nothing you normally use changes, because no page uses it. Whether a job also runs by itself while you are away is a separate setting, and this does not change it. A server started with the row off never loads the route's code. Turned off on a running server, the route goes at once, its code stays loaded until the next restart, and Thomas waits for a running job to end, which can take minutes. Stop now ends that wait and not the job, which goes on to its end and may still change or save files. In a run of all four, the jobs not yet begun do not start.
