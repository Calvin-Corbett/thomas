### Changed

- **The daily backlog landing can now be turned off and on while Thomas runs.** The two `/api/ratchet` routes and the ratchet's daily loop moved out of the server's fixed list into a row called Daily backlog landing, which ships on, so nothing changes until you turn it off. While it is off no daily run starts, those routes answer 404, and nothing you normally use changes, because no page in the sidebar reads them. Chat can still tell you what is unlanded from the ratchet's records, and a card already waiting for you can still be answered. If a run is going when you turn it off, Thomas now waits for that run, shows it as a job to finish, and offers Stop now, which says what stopping costs. Before this, the only way to stop a run was to stop the server. A release shows the row on, answers from empty records with the reason, and refuses a run. Turned off on a running server, the routes and the loop go, and the code stays loaded until the next restart.
