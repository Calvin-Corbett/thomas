### Changed

- **Every Thomas project's team starts with the lessons earlier hand-ins taught.** Each project began from the same blank brief, so the mistakes one team was sent back for, the next team made again. The notes every project's first message carries now also tell the team to run the tests and ruff on what it changed and say what it ran, to watch each new test fail with its fix taken out, to check every sentence it writes against the code, to delete files with the delete tool rather than empty them, and to resolve every conflict marker when dev was merged into its copy.
