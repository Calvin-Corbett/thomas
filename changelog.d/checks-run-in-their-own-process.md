### Changed
- The check before your card now runs in its own process instead of inside Thomas's server. Python runs one thread at a time in a process, so on 2026-10-27 five checks inside the server held its one core at 95 to 98%, and every request (health, the Code page, the teams' own calls) waited 60 to 120 seconds. Each check now has its own core; the server's thread waits for it, the landed-code reload still waits for it, and its timing notes come back with its verdict. A check process is ended when the server stops, and ends itself and its tests if the server is gone. Under tests, with `THOMAS_PRECARD_WORKER=off`, or with the parallel check off, it runs inside the server as before.
