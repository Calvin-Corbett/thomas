### Fixed

- **The "Open in Build" button in Chat's activity view shows an arrow again, not a bare dot.** It asks for `ph-arrow-up-right`, which was missing from the icon map in `chat_shell.css`; that name now draws the same arrow as `ph-arrow-square-out`.
- **A Work job's Pause and Resume buttons show their icons instead of bare dots.** `ph-pause` and `ph-play` had no entry in the icon map. Both buttons build the name from a template (`ph-${...}`), which the icon check could not read, so it never asked for them. The check now lists every template-built icon name with the names it can produce, and fails on a new template until it is listed.
- **You can move and resize the box for steering a running Code task in UI Edit Mode again.** A September change to that box dropped its edit-mode policy and its minimum size. The test that guards Code's editable regions still read `unified_code_mode.js`, which no longer draws any. Three of its checks failed for that reason and two passed with nothing to check, so the lost policy went unnoticed. It now reads `unified_code_surface.js` and `chat_workspace_navigation.js`, and fails if it finds no regions at all.
- **The Marketplace's live plugin controls load through the runtime manifest, like every other file in `js/runtime/`.** They had their own `<script>` tag in `index.html` instead, so the check that every runtime file is listed in `RUNTIME_SCRIPTS` failed. They still install once the runtime is ready, as before.
- **Work onboarding tells Thomas your real Tools settings.** Every onboarding turn said `Current Tools controls for this turn: {}`, because the Work page never handed its settings to the module that writes that line, so Thomas could not tell you when a setting you asked for differed from the one in use. A refused "Create job" now also gives the same reason the disabled button shows, including while Thomas is still replying.
- **Redesign keeps a change to what an element says.** When a redesign plan gave an element new words, the page dropped them before recording the change, so the label never changed.
