### Changed

- **Several checks before your card now run at once, instead of one at a time.** Each check, and each second look, runs on one of eight threads kept for them, never on the threads Thomas's server answers requests with, so even many checks waiting for their turn at once leave the server free to answer; a restart still waits, up to five minutes, for the checks and second looks already running. A check is admitted through the one reservation record both of Thomas's servers share: it reserves 2 GB on the drive its copies of dev go on (1.25 times the most one check used in the measured load run, and never less than 2 GB), and it starts only when that drive keeps at least 10 GB free after what every running check has promised. Waiting checks go fewest covering test files first, each gaining a place for every minute it waits, and one that has waited 15 minutes goes next. A check reads the commit it will land on again once its turn comes, so the time it waits for its turn never leaves it checking an older dev; dev moving while the check itself runs is still caught when the change is handed in. A check that finds no room, waits an hour without its turn, or cannot read the drive or the reservation record is held for another try with no strike against it, and never runs without its reservation. A check now runs up to 360 covering test files instead of 120, so the time saved goes into running more of the tests that cover a change, never fewer. A check that runs out of its hour while its tests spent longer waiting for a place in the shared pool of test processes than running is held for another try with no strike against it; one whose tests ran longer than they waited still counts as a strike. `THOMAS_PRECARD_PARALLEL=off` brings back one check at a time, with the earlier runner and the 120-file limit; set it the same way for both servers, because a server with it off reserves nothing in the shared record.
