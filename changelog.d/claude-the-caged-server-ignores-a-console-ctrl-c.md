### Fixed

- **A stray console Ctrl+C no longer stops the caged server or the Build runs it hosts.** The caged server runs as a background task with nobody at its console, but every Build runner and every test run of the check before your card shares that console, and a Ctrl+C sent to the console by any of them reached all of them. On 2026-09-26 its log read "[thomas] Stopped by user." with no user anywhere, and the keepalive had restarted it six times over two days, cutting off every run it hosted each time. `scripts/cage/caged_server.py` now turns a console Ctrl+C off for itself, and every process it starts inherits that. Task Scheduler can still end it and `/api/server/restart` can still restart it. The server started from your own console on port 8899 still stops on Ctrl+C as before.
