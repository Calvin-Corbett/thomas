### Fixed

- **"Already landed" now means the content landed, not just the words.** The earlier version returned success for a different change that had the same message and paths, and its "last 400 commits" limit did not limit anything. A trailer hit now has to match the content of the files that commit changed, and the search covers an explicit window of commits; a landing older than the window is tried again, which is the safe direction.
- **The lease can no longer be stretched, hung or outlived.** The length comes from the reaper's own setting (clamped to a ceiling), never from a holder's ledger line. The commit tool runs in a job object, so the lease bounds the return time and kills orphaned grandchildren; a surviving commit tool is killed by pid and start time before the next grant; abandoned git lock files are removed when no git runs, and reported.
- **A killed tool call no longer costs you your place.** `land.py --submit` and `land.py --wait N` (exit 5, still waiting) work in bounded slices while a worker process waits for you. Timeouts, withdrawals and killed waiters never count toward the attempt cap; honest refusals count toward a looser cap, and the cap follows your session-bound identity.
- **Smaller fixes from the review.** A wall clock that is set under a running poller reaps nobody, an unreadable heartbeat ages by its file, forged lane lines are ignored and reported, ticket numbers never go backwards, finished tickets are pruned and heartbeat writes are throttled, and the pre-check only runs when others are queued, at most two at a time. This is a queue, not protection: it is tamper-evident only.
