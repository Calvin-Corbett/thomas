# Retired marketplace module policy

Retired local marketplace module IDs must be blocked consistently across install, download, deep-link install, enable, disable, and import paths, while remaining hidden from discovery/sync/installed listings. Stale uninstall requests should remain safe/no-op.

Retired IDs covered by this policy:

- `life-manager`
- `life-manager-foundation`
- `brownies`
- `smart-home`
- `telegram-channel`

Paper Trading, Workforce, and chat games are active modules and must remain visible/usable.
