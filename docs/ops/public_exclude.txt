# Files a public release leaves out of the tree it publishes.

# One rule per line:  <path or pattern> | <why it stays private, in one line>
#   a path ending in "/"  leaves out everything under that folder
#   a pattern with * ? [  is matched against the whole path ("*" also crosses folders)
#   any other line        is one exact path
# Blank lines and lines starting with "#" are ignored. A rule with no reason is refused.
