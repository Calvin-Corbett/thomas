================================================================================
                         ALGORITHM IMPLEMENTATIONS
================================================================================

1. COLLABORATIVE FILTERING (collaborative.py)
   ├── UserBasedCF
   │   ├── find_similar_users()      - K-nearest neighbors by rating similarity
   │   ├── predict_rating()          - Weighted average from similar users
   │   └── recommend()               - Top-N recommendations
   │
   └── ItemBasedCF
       ├── compute_similarity_matrix() - Item-item similarity cache
       ├── find_similar_items()       - Similar items for each item
       ├── predict_rating()           - Weighted average from similar items
       └── recommend()                - Top-N recommendations

   Similarity Metrics: Cosine, Pearson, Adjusted Cosine
   Caching: Built-in similarity cache for performance

2. MATRIX FACTORIZATION (matrix_factorization.py)
   ├── ALSFactorizer (Alternating Least Squares)
   │   ├── _optimize_users()      - Fix items, solve for users
   │   ├── _optimize_items()      - Fix users, solve for items
   │   ├── _solve_linear_system() - Gaussian elimination
   │   ├── fit()                  - Train model
   │   └── predict_rating()       - Dot product + biases
   │
   └── SGDFactorizer (Stochastic Gradient Descent)
       ├── fit()                  - SGD training with shuffling
       ├── predict_rating()       - Dot product + biases
       └── recommend()            - Top-N recommendations

   Features:
   - Latent factors learning
   - User, item, and global bias terms
   - L2 regularization
   - Convergence checking
   - No external ML libraries

3. CONTENT-BASED FILTERING (content_based.py)
   ├── TFIDFVectorizer
   │   ├── build_vocabulary()     - Compute IDF values
   │   └── vectorize()            - Convert document to TF-IDF vector
   │
   └── ContentBasedRecommender
       ├── add_item_features()    - Add feature vectors
       ├── add_item_description() - Add text descriptions
       ├── _build_user_profile()  - Aggregate user preference profile
       ├── predict_rating()       - Cosine similarity match
       ├── recommend()            - Top-N recommendations
       └── recommend_by_item()    - Find similar items

4. SESSION-BASED RECOMMENDATIONS (session_based.py)
   ├── SessionBasedRecommender
   │   ├── _track_session()         - Track user interactions
   │   ├── _compute_cooccurrence()  - Items viewed together
   │   ├── _build_transition_matrix() - Markov chains
   │   ├── recommend_from_session() - Co-occurrence based
   │   ├── recommend_from_markov()  - Sequential patterns
   │   ├── recommend_combined()     - Blend both signals
   │   ├── get_session_similarity() - Jaccard index
   │   └── find_similar_sessions()  - Similar sessions to current

5. SIMILARITY METRICS (similarity.py)
   - cosine_similarity()           - Cosine distance (vectors)
   - pearson_correlation()         - Linear correlation
   - jaccard_similarity()          - Intersection / union (sets)
   - euclidean_similarity()        - 1 / (1 + distance)
   - adjusted_cosine_similarity()  - Bias-corrected cosine
   - hamming_similarity()          - Binary feature distance
   
   SimilarityComputer Class:
   - compute()                     - Compute with caching
   - pairwise_similarity()         - All pairs
   - similarity_matrix()           - 2D array form
   - get_top_similar()             - K most similar

================================================================================
                         EVALUATION METRICS
================================================================================

PrecisionRecall:
  - precision_at_k()              - Precision@K = hits / k
  - recall_at_k()                 - Recall@K = hits / relevant
  - f1_at_k()                     - Harmonic mean
  - avg_precision()               - Average precision
  - hit_rate()                    - Any relevant in top-K?

RankingMetrics:
  - ndcg()                        - Normalized DCG (rank quality)
  - map_at_k()                    - Mean Average Precision
  - mean_ndcg()                   - Average NDCG across queries

RatingMetrics:
  - rmse()                        - Root Mean Squared Error
  - mae()                         - Mean Absolute Error
  - mape()                        - Mean Absolute Percentage Error

CoverageMetrics:
  - catalog_coverage()            - Fraction of items recommended
  - novelty()                     - Inverse popularity score
  - diversity()                   - Average pairwise distance

RecommenderEvaluator:
  - train_test_split()            - Split data
  - evaluate_ranking()            - Full ranking evaluation

================================================================================
                         PIPELINE & ENSEMBLE
================================================================================

RecommendationPipeline:
  Stage 1: Candidate Generation
    - register_candidate_generator()  - Add strategy
    - generate_candidates()           - Get from all strategies

  Stage 2: Score Combining
    - combine_scores()                - Weighted average

  Stage 3: Filtering
    - add_filter()                    - Add business rule
    - apply_filters()                 - Apply all filters
    - filter_already_seen()           - Don't re-recommend
    - filter_by_score_threshold()     - Minimum score
    - filter_diversity()              - Distance-based

  Stage 4: Ranking
    - rank()                          - Final reordering

  Stage 5: Explanation
    - recommend()                     - Full pipeline

ExplanationGenerator:
  - generate_explanation()        - Human-readable why
  - explain_recommendations()     - Add to recommendations

A_BTestManager:
  - register_variant()            - Register variant
  - select_variant()              - Choose variant for user
  - recommend()                   - Get from selected variant
  - record_feedback()             - Log performance
  - get_statistics()              - Compare variants

================================================================================
                         TYPE SYSTEM & CONFIG
================================================================================

Data Types:
  - Rating                        - User rating with timestamp
  - Recommendation                - Item score with explanation
  - FeatureVector                 - Sparse features with norm caching
  - UserProfile                   - User history and features
  - ItemProfile                   - Item metadata and ratings
  - InteractionType               - Enum: VIEW, CLICK, PURCHASE, RATE
  - SimilarityMetric              - Enum: COSINE, PEARSON, JACCARD, etc.

Configuration:
  - RecommenderConfig             - Centralized config with validation
    ├── k                         - Number of neighbors
    ├── similarity_metric         - Which metric to use
    ├── min_ratings              - Minimum data requirement
    ├── latent_factors           - MF factor count
    ├── learning_rate            - SGD learning rate
    ├── regularization           - L2 penalty
    ├── iterations               - Training iterations
    ├── convergence_threshold    - Early stopping
    └── random_seed              - Reproducibility

Exceptions:
  - RecommenderError              - Base exception
  - ColdStartError                - New user/item problem
  - InsufficientDataError         - Not enough data
