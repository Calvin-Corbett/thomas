# Doc

Use this skill when Thomas needs to create, modify, or review Word documents where formatting and layout matter.

## Workflow
1. Inspect the requested document structure, source material, and fidelity expectations.
2. Apply the smallest document edits needed while preserving styles and section structure.
3. Validate headings, spacing, tables, and list formatting after edits.
4. Render or otherwise inspect the output when layout fidelity matters.
5. Summarize any remaining formatting caveats for the user.

## Rules
- Do not treat `.docx` files as plain text when formatting matters.
- Preserve existing document structure unless the task asks for a redesign.
