# Stream Clip Pipeline

Use this skill for creator-owned or explicitly licensed stream archives when Thomas needs to find highlights, package clips, and prepare repost metadata.

## Workflow
1. Confirm rights, platforms, and target clip formats.
2. Normalize transcripts, timestamps, and notable moments.
3. Score clip candidates by hook strength, context clarity, and repost suitability.
4. Build edit packets with titles, captions, aspect guidance, and publish notes.
5. Keep posting in dry-run mode until the user approves a publish step.

## Rules
- Never use this for unlicensed third-party ripping.
- Keep rights and platform compliance explicit.
- Default to review before publication.
