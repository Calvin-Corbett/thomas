# Figma

Use this skill when the task involves Figma URLs, node ids, design assets, variables, or design-to-code context gathering.

## Workflow
1. Identify the relevant Figma file, node, and design scope.
2. Extract the needed context: layout, typography, spacing, assets, variables, and states.
3. Map the design information to the current Thomas codebase or decision point.
4. Call out any ambiguity between Figma intent and implementation constraints.
5. Turn the result into actionable implementation guidance or code changes.

## Rules
- Do not guess at design details that Figma can answer directly.
- Keep extracted design context tied to the exact node or screen under discussion.
