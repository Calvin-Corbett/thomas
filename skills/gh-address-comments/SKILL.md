# GH Address Comments

Use this skill when Thomas needs to address GitHub PR review comments or issue feedback tied to the current branch.

## Workflow
1. Fetch the relevant review comments or issue feedback and group them by concrete action.
2. Resolve each comment with a code change, explanation, or justified pushback.
3. Run the nearest relevant verification after making changes.
4. Prepare concise reply text for each addressed thread when needed.
5. Summarize what was changed, what was answered, and what remains open.

## Rules
- Do not mark comments resolved without actually addressing them.
- Keep reply text concrete and tied to the actual fix or rationale.
