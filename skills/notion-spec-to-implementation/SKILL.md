# Notion Spec To Implementation

Use this skill when a Notion spec needs to be translated into executable engineering or project work.

## Workflow
1. Read the spec carefully and identify scope, success criteria, and dependencies.
2. Break the work into implementation phases or tickets with clear ownership boundaries.
3. Map the plan back to the original spec so traceability is preserved.
4. Flag ambiguities, missing acceptance criteria, or sequencing risks.
5. Deliver an execution-ready plan rather than a vague summary.

## Rules
- Do not treat incomplete specs as implementation-ready without calling out the gaps.
- Keep tasks aligned to actual deliverables and acceptance criteria.
