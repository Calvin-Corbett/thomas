# Develop Web Game

Use this skill when Thomas is building or debugging a browser-based game and needs a reliable implementation and verification loop.

## Workflow
1. Inspect the current game loop, controls, and rendering path before editing.
2. Make a narrow gameplay or UI change.
3. Run a browser-based smoke loop with short, deliberate interaction bursts.
4. Capture visual state, console output, and obvious gameplay regressions.
5. Iterate until the intended behavior is stable and reproducible.

## Rules
- Keep the gameplay proof loop tight and repeatable.
- Treat rendering glitches and console errors as part of the task, not background noise.
