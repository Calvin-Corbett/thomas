# Linear

Use this skill when Thomas needs to interact with Linear issues, projects, or planning workflows.

## Workflow
1. Identify the relevant issue, project, or team context.
2. Read the current state before proposing or applying updates.
3. Write concise issue content with clear scope, status, and next actions.
4. Keep links between implementation work and tracking artifacts explicit.
5. Report what changed in Linear and what follow-up remains.

## Rules
- Do not create duplicate tickets when an existing issue should be updated.
- Keep status and ownership language concrete.
