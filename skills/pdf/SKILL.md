# PDF

Use this skill when Thomas needs to work with PDFs and layout or rendered output matters.

## Workflow
1. Identify whether the task is extraction, generation, annotation, or layout review.
2. Use PDF-aware tooling rather than treating the file as plain text.
3. Inspect rendered pages when formatting fidelity matters.
4. Validate text extraction, pagination, and structural output after edits.
5. Summarize any fidelity limits or extraction caveats.

## Rules
- Prefer visual or rendered checks when the output is layout-sensitive.
- Preserve the distinction between extracted text and document appearance.
