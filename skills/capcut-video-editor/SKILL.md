# CapCut Video Editor

Use this skill when the user wants a CapCut-style editing workflow or when a video task benefits from fast caption-heavy editing and social cutdowns.

## Workflow
1. Confirm the source footage, delivery format, and target platform.
2. Build a fast edit plan around hooks, pacing, captions, and rhythm.
3. Prioritize trims, overlays, transitions, and text treatments suited to short-form delivery.
4. Review timing, readability, and export assumptions before finalizing.
5. Summarize the edit structure so a human or tool can reproduce it cleanly.

## Rules
- Favor speed and clarity over over-produced effects.
- Keep caption timing and mobile readability explicit.
