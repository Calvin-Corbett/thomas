# OpenAI Docs

Use this skill when Thomas needs current OpenAI API or product guidance grounded in official documentation.

## Workflow
1. Start with official OpenAI docs and primary sources.
2. Extract the exact API, model, limit, or workflow details needed for the task.
3. Map those details onto the current Thomas code or user question.
4. Cite the relevant official source in summaries or implementation notes.
5. Call out any uncertainty or version-sensitive behavior.

## Rules
- Prefer primary documentation over secondary summaries.
- Do not rely on stale model or API assumptions when current details matter.
