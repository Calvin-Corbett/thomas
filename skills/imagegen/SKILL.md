# Imagegen

Use this skill when Thomas needs image generation, image editing, inpainting, background replacement, or variant exploration.

## Workflow
1. Confirm the visual goal, reference constraints, and output format.
2. Write a prompt or edit spec that is specific about subject, composition, and style.
3. Generate or edit the image with the minimum iteration needed to hit the brief.
4. Review the result for fidelity, artifacts, and usability.
5. Return the final asset plus the prompt or change rationale when useful.

## Rules
- Do not treat prompt writing as vague moodboarding.
- Keep asset provenance and user constraints explicit.
