# Screenshot

Use this skill when Thomas needs an OS-level screenshot of the desktop, a window, or a specific screen region.

## Workflow
1. Confirm the target surface and the reason the screenshot is needed.
2. Capture the smallest scope that answers the question or proves the issue.
3. Name or organize the artifact clearly if multiple captures are involved.
4. Review the image to ensure the relevant UI state is actually visible.
5. Reference the screenshot directly in the follow-up explanation.

## Rules
- Do not capture broad desktop state when a narrower region is enough.
- Use screenshots as evidence, not as a substitute for analysis.
