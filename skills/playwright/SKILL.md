# Playwright

Use this skill when Thomas needs a real browser for verification, data capture, or repeatable UI workflows.

## Workflow
1. Navigate to the target page or local app.
2. Reproduce the flow with the minimum reliable browser actions.
3. Capture snapshots, screenshots, console errors, or network evidence as needed.
4. Turn observations into concrete fixes or proof artifacts.
5. Re-run the critical path after any UI change.

## Rules
- Prefer deterministic browser steps over vague manual descriptions.
- Keep browser evidence tied to the exact page state you tested.
