# Versioning And Changelog

Thomas uses Semantic Versioning and a user-readable changelog.

## Required For Any Behavioral Change

1. Bump versions:
- `pyproject.toml`
- `thomas/__init__.py`

2. Add a `CHANGELOG.md` entry:
- In a Keep-a-Changelog style section for that version
- Clear, user-readable bullets describing what changed and why

## Formatting Rules

- Prefer short bullets.
- Group by `Added`, `Changed`, `Fixed`, `Removed`.
- Include the date in `YYYY-MM-DD`.
