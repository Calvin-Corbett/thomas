# Definitions

This folder defines key words and protocols used by Thomas (and by agents working on Thomas).

- `definitions/autopoietic.md`: What "Level 5: Autopoietic" means for Thomas.
- `definitions/doppelganger-protocol.md`: Blue/green upgrade protocol (no risky live edits).
- `definitions/change-classification.md`: What counts as a safe vs breaking change.
- `definitions/scopes.md`: How to work on parts of Thomas without loading the entire world.
- `definitions/code-pruning.md`: When and how to remove code safely.
- `definitions/versioning.md`: Required version bump + changelog rules.
